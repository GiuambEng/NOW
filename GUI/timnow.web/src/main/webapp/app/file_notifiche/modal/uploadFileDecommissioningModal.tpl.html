Attenzione

Prima di dare conferma verificare la corretta formattazione del file:

  • La colonna "Id risorsa" deve essere importata sul file csv in caricamento nel formato di tipo "TESTO" per evitare che si perda il carattere "0" all'inizio del numero telefonico.
  • Il carattere separatore accettato alla fine di ogni riga (tranne l'ultima) e' il CR (formato Macintosh), per questo motivo il file deve essere salvato in formato "csv Macintosh".
  • Prima del caricamento e' necessario aprire il file csv creato e cancellare l'ultima riga vuota, poiche' il file deve terminare senza carattere separatore.
